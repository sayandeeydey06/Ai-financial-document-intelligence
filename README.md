🚀 AI Financial Document Intelligence Platform

🔹 Features:
- Upload invoices (image/PDF)
- OCR-based text extraction
- Rule-based financial data extraction
- Confidence scoring & risk flags
- Editable extracted data

🔹 Tech Stack:
- Frontend: React (Vite)
- Backend: FastAPI
- OCR: Tesseract
- Deployment: AWS S3 (frontend) + EC2 (backend)
